# 荧光强度测量使用指南

[English](guide.en.md) · [项目说明](../README_中文.md) · [分析方法](methods.zh.md)

本指南说明如何在星形胶质细胞的感兴趣区域（ROI）内测量一个目标通道的荧光强度，适合熟悉荧光图像、初次使用 Project Leap 和 Fiji 的实验室成员，无需编程经验。以下操作对应 Project Leap 中的 v1.1.0 模块；公开安装状态见[项目说明](../README_中文.md)。

## 开始前

使用运行 macOS 27 或更新版本的 Apple Silicon Mac。在 Project Leap 的“**功能与维护**”中安装“**星形胶质细胞荧光强度分析**”，等待显示“**模块已就绪**”。主程序会获取所需组件，无需手动安装模块压缩包。下文主程序控件使用中文名称；Fiji 控件保留其英文原名。

准备一个多通道 TIFF，分别包含 DAPI、eGFP 和／或 GFAP，以及 KCNN1、KCNN2、KCNN3、KCNJ10 中的一个待测标记物。合并后的 RGB 彩色图不适用。TIFF 需要保留深度轴及像素、切片间距，程序会自动读取。具体格式见[输入数据](methods.zh.md#输入数据)。

## 1. 导入图像

在侧栏选择“**星形胶质细胞荧光强度分析**”。在“**图像导入**”区域点击“**选择图像…**”，或拖入一个 `.tif`／`.tiff`。若出现选择提示，指定本次要分析的“**图像组（series）**”和“**时间点**”；一次运行处理这一组选择。

软件会显示图像尺寸、通道数、Z 层数、数据类型和体素标定。这些元数据由程序自动检查，无需手动填写或逐项重复验证。若提示缺少标定或格式不受支持，按报错向图像提供者获取正确导出的 TIFF，再重新导入。

## 2. 确认通道和图像年龄

在“**通道映射**”中确认预填选项，或将 C1、C2 等源通道分别指定为 **DAPI**、**eGFP** 和 **GFAP**。缺失的标记物选择“**未包含**”；必须包含 DAPI 以及 eGFP／GFAP 中至少一个。对“**待测通道**”，分别选择标记物名称和实际源通道。每个已选源通道只能对应一种标记物，未指定的源通道会被忽略。

软件可依据通道名称预填选项，但染色身份仍需你确认。显示颜色不能用来识别标记物；不确定时应向图像提供者确认。

在“**图像年龄**”中保留“**自动**”，或在已知样本类别时选择 **Mature** 或 **Neonatal**。存在 eGFP 时，“自动”依据图像形态选择处理配置，不会从 TIFF 读出动物的实际年龄。只有 DAPI + GFAP、没有 eGFP 时，**仅对成熟样本**使用“自动”或 Mature；这条 GFAP-only 路径不支持新生样本。导入另一张图像后，年龄选项会重置为“自动”。

## 3. 开始分析

在分析状态区域点击“**开始分析**”。程序在独立任务目录中生成带物理标定的单通道工作 TIFF，随后选择分析深度并构建整细胞、胞体和突起 ROI。原始 TIFF 的内容和位置保持不变。

若无法开始，查看模块状态、必需的图像组／时间点选择、通道分配和 GFAP-only 年龄设置。分析期间保持 Project Leap 和 Fiji 打开。主程序显示“**等待 Fiji 审核**”后，点击“**前往 Fiji 审核**”将其窗口置于前台。

## 4. 在 Fiji 中检查拟定区域

在 **Astrocyte ROI Reviewer** 对话框中点击 **Review ROIs**；关闭这个初始对话框会取消运行。随后打开三个管理器：**Whole Astrocyte Cell ROI Manager** 管理整细胞，**Astrocyte Soma ROI Manager** 管理胞体，**Astrocyte Processes ROI Manager** 管理突起。每个管理器对应一幅 Composite 合成图和一幅 Raw Grayscale 原始灰度图，共六个视图。**Astrocyte ROI Reviewer-Waiting** 窗口提供结束审核和撤销等控件。

点击任一管理器中的细胞行，可在各视图中高亮该细胞；**Show ROI Images** 将对应的两幅图置于前台。在活动图像中按 **+** 或 **−** 缩放，按住 **Space** 并拖动可平移。多选时先点击第一行，再按住 Command 点击其他行。

检查边界是否沿目标细胞结构分布，是否错误包含其他细胞或背景；用原始灰度图检查待测信号。编辑后编号可能变化，因此需要重新确认所选 ID。程序的技术检查通过后，仍需完成这些生物学判断。

## 5. 按需修正区域

| 观察到的问题 | 操作位置、动作和反馈 |
|---|---|
| 不应保留的细胞 | 在任一管理器选择该行，点击 **Delete Selected ID(s)**，该细胞的三类区域会一起删除。程序不允许删除最后一个细胞；若已无有效细胞，选择 **Cancel Analysis**。 |
| 一个细胞被分成多个 ID | 在 Soma 管理器选择至少两行，点击 **Merge Selected Soma IDs**。程序检查这些胞体边界能否以不超过 **1.0 µm** 的相邻间距连成一组，无需人工测距。距离条件不满足时区域不变；合并成功后检查三类区域。 |
| 一个整细胞 ROI 包含多个细胞 | 在 Whole Cell 管理器只选一行，点击可用的 **Split Selected Whole Cell**。程序寻找一个有依据的额外 DAPI 细胞核，并重新计算为两个细胞；证据不足时会拒绝拆分，完成后需检查结果。 |
| 胞体区域过小 | 在 Soma 管理器只选一行，点击可用的 **Enlarge Selected Soma**。程序根据局部证据重算胞体边界，同时更新其他区域。 |
| 需要去掉部分突起 | 在 Processes 管理器打开 **Trim Processes**，按下列步骤绘制并确认草稿。 |

修剪突起的步骤：

1. 在任一 Composite 合成图中，用自由手绘区域圈住不需要的部分并松开鼠标。无需预先选择细胞；一次圈选可以涉及多个细胞。
2. 点击 **Preview Trim**，检查受影响的 ID 和黄色标出的拟删除区域。此时正式 ROI 边界尚未改变。首次预览后，继续绘制或修改草稿会自动更新预览。
3. **Clear Cell Draft** 清除当前选中受影响 ID 的草稿；**Undo** 撤销一步草稿操作；**Cancel** 放弃整个未确认草稿。
4. 等待当前预览完成，再点击 **Confirm Trim**。程序从整细胞和突起区域中同步删除接受的像素，胞体保持不变。预览过期、未删除任何突起像素、某个细胞的突起将被全部删除，或保留的突起将与胞体产生新的断连时，程序会阻止确认；按提示修改草稿。

**Cell Edit: ready** 只表示计算已经结束，不能单凭这条状态判断编辑成功；需阅读消息并检查边界。被拒绝的尝试保留此前 ROI。要停止 Split 或 Enlarge，点击 **Cancel Cell Edit** 并等待取消完成。要撤销已应用的修改，先关闭 Trim，等待当前计算结束，再在 Waiting 窗口点击 **Revert**。连续点击会按逆序撤销已应用的编辑；一次确认的 Trim 会整体撤销。Trim 中的 Undo 仅作用于尚未确认的草稿。

## 6. 结束审核并查看结果

若 Trim 仍打开，使用 **Confirm Trim** 应用有效草稿，或用 **Cancel** 关闭；空草稿也用 Cancel。等待计算或取消操作结束后，在 **Astrocyte ROI Reviewer-Waiting** 中点击 **Finish Review and Measure**。Project Leap 会自动继续，显示“**已完成**”后点击“**查看分析结果**”。

打开 `IHC_2D_Fluorescence_Results.xlsx`，选择 **Whole Cell**、**Soma** 或 **Processes** 工作表。每行对应一个细胞在该区域的测量值，`Astrocyte_ID` 与叠加图编号对应；`Mean` 是 ROI 内像素强度的平均值，`Median` 是中位数。**Review Audit** 记录已应用和已撤销的编辑。

测量来自软件所选深度范围的二维投影。待测强度没有经过背景扣除或强度归一化；显示颜色不会改变测量值。工作簿记录投影方式和 Z 范围，便于确认具体测量对象。

程序完成验证后，将以下六个文件一起保存：

| 文件 | 内容 |
|---|---|
| `IHC_2D_Whole_Astrocyte_Overlay.png` | 整细胞边界及编号 |
| `IHC_2D_Astrocyte_Soma_Overlay.png` | 胞体边界及编号 |
| `IHC_2D_Astrocyte_Processes_Overlay.png` | 突起边界及编号 |
| `IHC_2D_Analysis_Report.txt` | 分析设置、选择依据和运行报告 |
| `IHC_2D_Fluorescence_Results.xlsx` | 三类区域的测量值及编辑记录 |
| `IHC_2D_ROI_Archive.zip` | 最终标签图、ImageJ ROI、标定、身份信息及其与测量的对应关系 |

请保留结果文件夹和原始 TIFF。ROI 归档保存最终区域形状；当前软件没有一键重新打开已结束荧光任务继续编辑的入口。

## 7. 处理停止的任务与维护模块

取消或失败后，返回本模块，处理报错指出的问题，再点击“**开始分析**”启动新任务。查看当前任务时，向下滚动到分析控件下方的“**运行细节**”，阅读状态和运行日志。查看已保存任务时，打开“**任务与结果**”，选择任务，再点击“**运行细节**”旁的“**展开**”，阅读保存的摘要。`z_step_limit` 表示 eGFP 路径无法在当前图像深度内安排所需窗口，应使用符合要求的采集图像，不应虚构切片间距。`z_selection_ambiguous` 表示最高位置得分并列，程序未选择最终位置。

如果主程序关闭时后台进程仍在运行，重新打开软件可以重新连接该任务；后台已退出时，任务可能被标记为中断。这不代表任意计算或 Fiji 会话都能断点恢复。

在“**任务与结果**”中查看历史结果；软件要求修复模块时，前往“**功能与维护**”操作。临时数据应通过软件的清理控件处理。删除任务会删除该任务管理的数据和结果，删除前先导出需要保留的文件；外部原图和已导出的副本不在删除范围内。
